# HW1: Lexer, Regex -> DFA -> Minimization

Учебная реализация лексера Funny на Java без внешних библиотек.

## Запуск

Требуется JDK 11 или новее:

```text
javac -encoding UTF-8 *.java
java Main
```

В PowerShell используйте `javac -encoding UTF-8 (Get-ChildItem *.java).Name` вместо первой команды.

Команда строит общий НКА методом Томпсона, преобразует его в ДКА методом subset construction, минимизирует ДКА алгоритмом Хопкрофта и запускает встроенный набор тестов.

Результаты создаются в текущем каталоге:

- `dfa.json` - сериализованная таблица переходов по ASCII-алфавиту;
- `Report.md` - регулярные выражения, статистика, описание trap-состояния и таблица тестов.

Приоритет токенов задается порядком в `Token.specification()`. Лексер использует максимальную длину совпадения, затем приоритет. `WS` и `COMMENT` пропускаются. Неопределенные ASCII-символы и non-ASCII попадают в `ERROR` через trap-состояние.

## Поддерживаемый синтаксис regex

Парсер реализует литералы и экранированные литералы, конкатенацию, `|`, `*`, `+`, `?`, круглые скобки, символьные классы с диапазонами и отрицанием, а также `.` для ASCII-алфавита. Внешние regex-библиотеки не используются.
